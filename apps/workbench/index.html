Smoji 接入与规范指南

Ecoku Smoji v1 Specification

工作台功能

  • 整包 / 自选双模式：勾选源分类整包导出，或创建最多 64 个自选分组精选表情。
  • 本地持久化：自选分组、勾选状态、主题与密度会自动保存在浏览器本地。
  • 分组可移植：自选分组支持导入/导出 JSON（smoji-custom-groups）。桌面端可从网格拖入托盘、拖拽排序与跨组投放；触控端用分组 ↑↓、托盘 ◀▶（边缘可跨组）与 Alt 快捷键。展开空分组可点选为目标或拖入表情。
  • 浏览与预览：按分类浏览，自选分组可切换「源分类 / 已入组」。点击图片查看原图和动图，使用底部导出栏保存配置。

快捷键

  • Ctrl+1/2 — 切换整包导出 / 自选分组
  • Ctrl+E — 导出当前配置（底部 Dock）
  • Ctrl+. — 聚焦导出格式选择
  • Ctrl+Shift+P — 打开数据预览
  • Ctrl+D — 切换紧凑 / 舒适密度
  • ↑↓←→ — 网格内移动；Enter/Space 打开详情
  • Ctrl+Z — 撤销最近移出 / 删除 / 清空分组
  • 详情弹层：←→ 切换；1–5 选格式；Esc 关闭
  • Alt+↑/↓ — 自选分组列表上移/下移
  • Alt+←/→ — 托盘内调序；触控 ◀/▶ 在首/末项可跨到相邻分组
  • ? — 打开本指南

核心特点与边界

  • 零运行时依赖：仅消费轻量 ES2020+ 标准 API，体积严格控制在预算内。
  • 单文件清单规范：唯一数据契约 smoji.json，格式为 { version: 1, packs: [...] }。
  • 严格防注入安全设计：标签仅用 textContent 绑定，安全渲染器避免 innerHTML。
  • 可扩展分组包：导出自选分组 JSON 可携带 extensions；内置 smoji.workbench 会同步导出格式与备注。第三方可通过 registerPackGroupExtension / registerExportFormat 接入。
  • 历史内容永续性：标记序列化为绝对图片地址 ![smoji:标签](https://...)，未来清单增删不影响历史评论。

规范约束限制

1 ~ 64 最大表情包分组数
1 ~ 600 每分组最多表情项
≤ 6000 单清单总表情数上限
≤ 1024 KB 清单文件体积上限

多平台导出格式对照

下载文件名包含 UTC 日期后缀（YYYYMMDD）。部署时可重命名；配置中的 URL 应与实际部署的文件名一致。

格式 目标应用 / 插件 文件名
Smoji v1 Ecoku 原生评论系统、Smoji Picker 官方核心库 smoji-YYYYMMDD.json
Artalk Artalk 自托管评论系统 v2+ artalk-YYYYMMDD.json
Twikoo Twikoo 无服务器评论系统 twikoo-YYYYMMDD.json
OwO Valine 及各类兼容 OwO 规范的独立博客 OwO-YYYYMMDD.json
Waline Waline emoji 配置对象数组 waline-YYYYMMDD.json
